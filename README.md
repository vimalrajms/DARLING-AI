# Darling Robot Website v2 — Free Phase 1

This is a front-end demo for Darling Robot. It uses basic local rules and does not need an API key or paid AI service.

## Run on Windows
1. Extract the ZIP into a folder, for example `E:\DARLING_ROBOT_WEBSITE`.
2. Double-click `index.html` to open it in your browser.
3. Optional: open Command Prompt in this folder and run `python -m http.server 5500`.
4. Visit `http://localhost:5500`.

## Included
- Responsive cyberpunk Darling Robot design
- Basic text chat with English/Tanglish keyword matching
- Jokes, riddles, motivation and simple calculations
- No API key and no pair code displayed

## Not included yet
Real AI backend, ESP32/OLED connection, Bluetooth earbuds voice chat, cloud sync or remote multi-phone chat. This is a browser demo; messages are not sent to a server and replies are not generated by a real AI model.
